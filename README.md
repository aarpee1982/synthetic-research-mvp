# Synthetic Market Research

Source for [syntheticmarketresearch.com](https://www.syntheticmarketresearch.com), a Vercel-hosted Next.js site.

## Local Development

```bash
npm install
npm run dev
```

## Deployment

This repo is connected to the Vercel project:

`rahulpanditamarketing-2088s-projects/synthetic-market-research`

Git pushes to `main` should create Vercel deployments.
